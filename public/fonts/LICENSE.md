# Fonts

Both families are self-hosted variable fonts, subset to Latin and Latin
Extended, and licensed under the SIL Open Font License 1.1.

- **Fraunces** — Copyright 2020 The Fraunces Project Authors.
  https://github.com/undercasetype/Fraunces
- **Source Sans 3** — Copyright 2010–2023 Adobe.
  https://github.com/adobe-fonts/source-sans

Files were taken from the Fontsource distributions of each family
(`@fontsource-variable/fraunces`, `@fontsource-variable/source-sans-3`) and
vendored here so they can be served from a stable, preloadable URL with no
runtime dependency. Only the upright weight axis is shipped; italics are
synthesised nowhere in the design and `font-synthesis` is disabled.
